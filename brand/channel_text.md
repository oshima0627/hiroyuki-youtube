競合の `ひろゆけ` は5語しか入れていない。ここは上限500文字まで入るので、
**うちが実際に出しているテーマ語（仕事・お金・子育て・フランス・睡眠）を入れる。**
在庫のテーマと揃えておくと、テーマ別に伸びたときに拾われる。

## 反映の仕方

説明文とキーワードは `channels.update`（part=brandingSettings、50ユニット）で
入れられる。**ただしアカウント設定の変更なので、実行前に必ず確認を取ること。**
バナーは `channelBanners.insert` があるが、**プロフィール写真に API は無い**ので
Studio から手で上げる。
